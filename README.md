## Project Description
This project predicts whether a customer is likely to leave a telecom service using machine learning.

## Dataset
IBM Telco Customer Churn Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
1. Logistic Regression
2. Random Forest

## Results
Logistic Regression achieved the best performance:
- Accuracy: 80.7%
- Precision: 65.8%
- Recall: 56.7%
- F1-score: 60.9%
- ROC-AUC: 0.842
